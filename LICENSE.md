# Licenses of each asset

## Characters/

The Mixamo characters were removed because Mixamo's license disallows for redistribution. You can do a reasonable job of reconstructing them by downloading each of the animations you want and combining them into one GLB file with [Mixamo2GLTF](https://mixamo2gltf.com/). I used [Standard](https://www.mixamo.com/#/?page=1&query=Standard&type=Motion%2CMotionPack) walk, run and idle, but for jump I made a freeze frame of [Jumping Up](https://www.mixamo.com/#/?page=1&query=Standard&type=Motion%2CMotionPack) (the fast one, in the Action Adventure Pack) in Blender.
